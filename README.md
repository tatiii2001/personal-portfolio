## About me

I'm a **Developer & Software Crafter** interested in building software that makes
sense — not only when it works, but also when you come back to the code months later.

I enjoy working across frontend, backend and domain layers, with a particular
interest in software architecture, maintainable code and continuous learning.

I'm also exploring how **AI and agentic workflows** can become part of the software
development lifecycle while keeping engineering practices, human review and
sustainable code at the center.

## Built with

This portfolio was intentionally built with a simple stack:

- HTML5
- CSS3
- Vanilla JavaScript

No frontend frameworks, UI libraries or animation libraries.

The goal was to use the simplest tools that made sense for the project while
keeping the experience responsive, accessible and maintainable.
